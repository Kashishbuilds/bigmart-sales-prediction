# 🛒 Big Mart Sales Prediction App

## 📌 Overview
This is a Machine Learning web app built using Streamlit that predicts product sales in retail stores using XGBoost.

## 🚀 Features
- 🔮 Sales Prediction
- 📊 Insights Dashboard
- 📈 Visualization

## 🧠 ML Model
- Algorithm: XGBoost Regressor
- Type: Supervised Learning (Regression)

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Scikit-learn
- XGBoost

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
